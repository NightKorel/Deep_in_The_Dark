# 潛淵（Deep in the Dark）

一款純前端（HTML + CSS + 原生 JavaScript，無框架、無需安裝）的中文 Roguelike 探索戰鬥遊戲。
你墜入一道會吞人的裂谷「潛淵」，和夥伴在避難所落腳，一次次往更深的圈層探索——打怪、蒐集資源、
變強，設法在這片黑暗裡活下去、往下走。

> 劇情不在這裡劇透，進遊戲慢慢體驗。

## 怎麼玩

不用編譯、不用伺服器，直接用瀏覽器打開 `index.html` 就能玩（Chrome / Edge / Firefox 皆可）。

- **存讀檔**：進度不會自動存。用左上角 `☰` 選單的「💾 存檔」把進度下載成一個 `.json` 檔自己保管，
  下次用「📂 讀檔」讀回來。

### 基本玩法

- **深潛探索**：從避難所出發往下潛，一格一格走。每格會遇到不同節點（小怪／菁英／Boss／休息／
  各種事件／商人／寶藏／賭局…），自己選路線。
- **回合制戰鬥**：隊伍與敵人輪流出手，看敵人頭上的意圖圖示（⚔️ 攻擊／☠️ 異常／⚡ 蓄力／❓ 其他）
  決定怎麼應對。全隊倒下不會真的死人，只會損失這趟部分收穫、被捲回避難所。
- **避難所變強**：用主要貨幣「潛晶 💎」在工坊強化武器／裝備、煮料理、製魔藥，整備後再出發。
- **成就與遺物**：達成成就會拿到永久的「遺物」（裝在角色身上的被動加成）。未解鎖的成就會遮起來防暴雷。
- **賭場**：潛淵深處藏著一位神秘莊家，達成特定條件後可以找他玩幾局賭博小遊戲。
- 想快速體驗：左上角 `☰ → 🔧 作弊` 選單有跳序章、通關、升等等測試功能（給測試員用）。
