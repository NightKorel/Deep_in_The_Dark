# 潛淵（Deep in the Dark）

一款純前端（HTML + CSS + 原生 JavaScript，無任何框架、無需安裝）的中文 Roguelike
探索戰鬥遊戲。開場被獻祭般丟入會吞人的裂谷「潛淵」，在避難所與夥伴 K、V 重整旗鼓，
一次次深潛、打怪、蒐集資源，最終擊敗 Boss「島鯨」救出失蹤的隊友 L。

## 怎麼玩（執行方式）

不需要編譯、不需要伺服器，直接用瀏覽器打開 `index.html` 就能玩。

- 最簡單：把 `index.html` 拖進 Chrome / Edge / Firefox。
- 存檔機制：遊戲進度**不會自動存**。用左上角 `☰` 選單的「💾 存檔」把進度下載成
  一個 `.json` 檔自己保管，下次用「📂 讀檔」讀回來。關掉視窗＝放棄這趟深潛的暫存狀態。

## 專案結構

```
index.html                     入口，依序載入下面 6 個 js 檔
style.css                      全部樣式（深色主題）
js/
  01_資料庫.js                 純資料：角色/技能/怪物/節點/遺物/料理/各種數值常數
  02_介面共用與存讀檔.js       gameState 定義、數值計算、畫面切換、對話系統、存讀檔、作弊選單
  03_開場劇情.js               21 段開場劇情 + 固定劇本的教學戰鬥
  04_避難所.js                 避難所：工坊(強化)/家(煮飯·技能·出發·藥水)/煉藥站 + 回程結算
  05_深潛.js                   深潛探索：節點選路、各種非戰鬥事件、遺物管理、藥水/料理操作
  06_戰鬥.js                   回合制戰鬥引擎：傷害計算、敵人 AI、狀態效果、獎勵結算
```

載入順序有相依性（`index.html` 裡的 `<script>` 順序），01 是純資料要最先載入，
其餘檔案彼此以全域函式互相呼叫。

## 核心概念速查

- **兩層狀態**：`gameState`（避難所的永久進度，會存檔）與 `activeDive`（單趟深潛的
  暫存狀態，不存檔）。定義都在 `02_介面共用與存讀檔.js`。
- **潛晶 💎**：主要貨幣，用來強化裝備、補藥水、商店交易；回避難所要扣「維護費」，
  不夠的話工坊會暫時停擺。
- **深潛流程**：第一圈層固定 10 格（`LAYER1_NODE_CONFIG`），每格從 1~3 個節點類型中
  選一個走。節點類型：小怪/菁英/Boss/休息/奇異地形/代價交換/商人/隨機事件/寶藏。
- **戰鬥**：固定隊伍出手順序 K → 主角 → V（L 救出後加在最後），敵人頭上的意圖圖示
  ⚔️攻擊 / ☠️異常 / 🌀蓄力 / ❓其他。全滅只損失這趟一半潛晶，不會真的死人。
- **成長軸線**：角色等級（解鎖技能）、武器強化（攻擊力）、裝備強化（血量）、
  遺物（個人被動）、全局增益（單趟深潛內生效）、料理 buff（下場戰鬥生效）。

## 角色

| 角色 | 武器 | 定位 |
|------|------|------|
| 主角 | 劍 | 平衡，可格擋嘲諷、自我回復 |
| K | 雙刀 | 輔助，治療 / 群攻風刃 / 全隊增傷 |
| V | 匕首 | 高攻，流血 / 爆擊 / 蓄力爆發 |
| L | 法杖 | 打贏 Boss 救出後入隊，冰系法傷 / 持續回血 / 減傷 |
