# 潛淵 — 檔案地圖（給編輯者/Claude 快速定位用）

> 目的：一看就知道「哪個功能在哪個檔、哪個函式」，不用每次翻整包程式碼，省時間省 token。
> **規則：改動或新增功能後，要順手更新這份地圖；每次動工前也要先看這份地圖找位置。**（見 CLAUDE.md）

## 載入順序（index.html）
`01_資料庫` → `02_介面共用與存讀檔` → `03_開場劇情` → `04_避難所` → `05_深潛` → `06_戰鬥` → `07_成就` → `08_賭場` → `09_劇情記錄`
（01 是純資料要最先載入；其餘檔案彼此用全域函式互相呼叫。）

---

## 各檔案負責什麼

### 01_資料庫.js — 純資料（沒有邏輯）
角色 `CHARACTERS`、技能 `SKILLS`、狀態常數、怪物 `MONSTERS`＋`MONSTER_SKILLS`、
圈層資料 `LAYERS_META`／`LAYER_BOSS`／各層怪物池／菁英組合 `ENEMY_GROUPS_LAYERx`、
節點配置 `LAYERx_NODE_CONFIG`、奇異地形 `ODDITY_EVENTS`、代價交換 `COST_EXCHANGE_OPTIONS`、
隨機事件 `RANDOM_EVENTS`、寶藏/商店、食材料理 `FOODS`、藥材魔藥 `HERBS`/`POTIONS`、遺物 `RELICS`、全局增益 `GLOBAL_BUFFS`。
- 要調數值、加怪/技能/遺物/事件/料理 → 大多在這裡。
- **🔮`ODDITY_EVENTS` vs ❔`RANDOM_EVENTS` 定位（別搞混）**：🔮＝安全強化/補給（只給 buff/回血、零風險、不給潛晶遺物）；
  ❔＝有賺頭但有風險（潛晶/藥/遺物＋受傷/戰鬥/空手）。加新內容照這分工放（規則詳見 `ODDITY_EVENTS` 上方註解）。

### 02_介面共用與存讀檔.js — 共用邏輯＋存讀檔＋各種選單
`gameState`（存檔的資料結構）、小工具（randInt/chance…）、角色數值計算（getCharacterMaxHp…）、
畫面切換 `showScreen`/`updateTopStatusBar`、通用彈窗 `openGenericModal`、改名、設定、
**作弊選單 `openCheatModal`＋各 cheat 函式**、通知 `systemToast`、
**對話劇情層 `playDialogue`/`showNextDialogueLine`（劇情記錄 `recordStoryLog` 也在這）**、
存讀檔 `collectSaveData`/`applySaveData`、入口 `initGame`。
- 要改存檔欄位 → `gameState` ＋ `collectSaveData` ＋ `applySaveData` 三處一起改。
- 要加對話 → 用 `playDialogue(lines, onComplete, logInfo?)`。
- **劇情逐字動畫**：`typeDialogueText`（逐字/整句）＋`finishTypewriter`（點一下秒顯示）＋`revealDialogueControls`
  （字跑完才擺選項/輸入框）；速度常數 `TYPEWRITER_SPEED`。開關在 `gameState.settings.typewriter`（設定選單）。
- **Auto 自動下一句**：`cycleDialogueAuto`（關/慢/中/快循環，按鈕 id `dialogue-auto-btn`）＋`scheduleAutoAdvance`
  ＋`renderDialogueAutoBtn`；延遲常數 `AUTO_DELAYS`，狀態存 `gameState.settings.autoMode`。
  計時器統一由 `clearDialogueTimers` 收乾淨（`showNextDialogueLine` 與作弊跳教學都會呼叫）。

### 03_開場劇情.js — 新手開場
21 段開場（墜落→教學岔路→固定劇本教學戰鬥→認識 K/V→命名→世界觀→轉入避難所）。
`startOpeningStory`→`continueOpeningAfterFight`→`continueOpeningAfterNaming`→`finishOpeningStory`；
作弊 `cheatSkipTutorial`。

### 04_避難所.js — 避難所各設施
工坊（強化武器/裝備、製藥）、家（煮飯/技能管理/整備出發/補血藥）、
**整備出發＋圈層下拉選單 `showDepartScreen`/`departLayerChoiceHtml`/`confirmDepart`**、
圖鑑（怪物/料理/魔藥）、回程結算 `applyShelterReturn`。

### 05_深潛.js — 探索（走地圖）
圈層工具（依 `activeDive.layer` 取節點/怪物池/Boss）、出發初始化 `startNewDive`、
畫面渲染 `renderDiveScreen`（含 Boss 門前劇情）、節點分派 `chooseNode`、
各節點：戰鬥/休息/奇異地形/代價交換/隨機事件/寶藏/商店、
**Boss 戰後劇情 `handleLayer1BossVictory`/`handleLayer2BossVictory`**、
作弊 `cheatCompleteLayer1`/`cheatCompleteLayer2`。

### 06_戰鬥.js — 回合制戰鬥引擎
建立戰鬥 `startBattle`、回合流程 `beginRound`/`tickStatusEffectsAll`、敵人 AI `chooseEnemyIntent`/`executeEnemySkill`、
**傷害計算 `damageCalc`/`dealDamageToAlly`/`dealDamageToEnemy`**、玩家行動、
**補血藥 `battleDrinkPotion`（直飲30%）/`battleApplyPotion`（外敷HoT，第二層Boss後解鎖）**、戰鬥結束/獎勵、
畫面渲染 `renderBattleScreen`、**視覺反饋 `flashUnit`/`spawnFloatingNumber`（飄傷害數字）**。

### 07_成就.js — 成就
`ACHIEVEMENTS`（清單）、`checkAchievements`（統一解鎖）、`openAchievementsModal`（一覽，未解鎖只顯示圖示+???）。
- 加成就 → 往 `ACHIEVEMENTS` 加一條，寫好 `check()`。

### 08_賭場.js — 賭場（H）
節點賭場（賭潛晶）＋避難所賭場（代幣）、共用下注列、各款遊戲（翻礦盤/逼深骰/騙子骰/深淺牌/破譯/記憶迴光）、
解鎖判定 `isShelterCasinoUnlocked`。詳規見 `設計文件/賭場設計.txt`。

### 09_劇情記錄.js — 劇情回顧
從 `gameState.storyLog`（玩過才有）讀出主線段落，選單 `openStoryLogModal`／看單段 `showStoryLogScene`。
- 要讓某段對話進回顧 → 在該 `playDialogue` 第三參數傳 `{ id, title, order, append? }`。

## 常見「我想改 X，去哪找？」
- 某個數值（血量/傷害/掉落/價格） → `01_資料庫.js`
- 某段劇情台詞 → 開場在 `03`；Boss 門前/戰後在 `05`；其餘節點事件文字多在 `01`(資料) 或 `05`(觸發)
- 存檔壞了/加存檔欄位 → `02` 的 `gameState`＋`collectSaveData`＋`applySaveData`
- 戰鬥手感/傷害/視覺 → `06`
- 賭場 → `08`（＋`設計文件/賭場設計.txt`）
- 成就 → `07`
- 出發/避難所設施 → `04`
