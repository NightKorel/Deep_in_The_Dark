## 0. 一句話總綱

潛淵從「卡在 RPG 與 roguelike 中間」的四不像，**明確改成 Roguelite**：
**永久成長＋劇情戰役當骨幹（保留角色與故事），單趟下潛是真正的一趟（半隨機、臨時 build、越深越險、見好就收 vs 貪心），全滅＝這趟消散、永久的留著。**

最高設計原則（貫串全部）：
> **永久層只「解鎖廣度／可能性」，不直接加數值強度；單趟層才負責「這趟變多強」。**
> → 難度永遠是「這趟組得好不好」，跟刷多久無關，平衡不會因為玩久了就崩。

## 1. 世界觀基石：輪迴 meta（皇冠上的寶石，別漏掉）

這是把「roguelite 的死亡重來」變成劇情核心的關鍵設定——機制即敘事（黑帝斯那套）。

- **潛淵有輪迴**：劇情上，K/V/L 他們是「拼中了無數次失敗中湊巧成功的那一次奇蹟」，才通關並走出潛淵。
- **玩家玩的每一趟 run ＝ 一條時間線**；全滅 ＝ 一條失敗的時間線，時間線重來。
- **主角（玩家）是唯一記得所有輪迴的人**：「你操控時間線、記得每一次死亡，你拯救他們，也拯救你自己。」
- **潛晶為什麼永久保留** → 因為它是主角**跨時間線帶回來**的東西（只有主角記得）。
- **夥伴留「朦朧的夢感」**，不是完全不記得。規則：夥伴不記得細節，但（考慮）輪迴越多、既視感/夢的殘留越強。
- **跟「祝福出潛淵就消散」天衣無縫**：祝福＝這條時間線裡臨時借來的潛淵之力，時間線重來就消散；只有主角記得的（潛晶）永久帶走。

### 揭露節奏（納可拍板：提示要很淡）
- **不要明顯**。第一次死亡回家時，K **只**說類似「咦，居然有這麼多潛晶，你太厲害了！」——
  只留一個「潛晶怎麼變這麼多」的小違和，敏銳玩家會起疑、遲鈍的看不到。**連「做夢」都不明講**。
  （反差：K 天真地誇，他不知道主角經歷了什麼，只有主角和玩家知道——比明講更揪心。）
- 真相（主角是時間線操控者）**慢慢揭露、終盤才揭曉**，接上「防暴雷、還沒解鎖不預告」原則。
- **避坑**：meta「反正會重來」最怕死亡沒重量。破解＝**主角記得每一次夥伴的死**，對世界是重來、對主角是一次次真實的痛。守住這點，輪迴才不落入虛無、反而是全作最沉的情感內核。
- 伏筆回收點：邀請出發時那句「一旦往深處走，或許就不能回頭」，之後回扣——其實他們「回頭」過無數次（每次死亡重來），只是不記得，只有主角記得。

## 2. 成長系統（兩層分開）

### 2A. 永久層 ＝ 潛晶（唯一的「能力／內容」解鎖貨幣，管「實力」）
潛晶靠下潛賺，是**唯一**買得到「變強／改變玩法」的貨幣，用途集中：
- 解鎖技能（一次性）
- 升**歷練** → **提高潛化欄位上限**（歷練重新定位：**不再加傷害**，改成「能駕馭更多潛淵之力＝多帶一格祝福」；維持「很久升一次、一次有感」的大跳）
- 把**祝福解進池子**（讓下潛能撿到更多種祝福）
- 開新圈層入口、解鎖角色

> 保留既有簡化：砍經驗值/等級、潛晶＝唯一貨幣。**砍掉**舊的「武器/防具強化等級」與「歷練加傷害」那套。

### 2B. 單趟層 ＝ 潛化祝福（見第 3 節）＋遺物（見第 4 節）
這趟沿路撿、把隊伍現場改裝，出潛淵消散。**強度都在這層。**

## 3. 潛化祝福（單趟 build 的主體）

**一句話：一趟下潛沿路吸收潛淵之力，把隊伍現場改裝成「這趟限定」的 build，出潛淵消散。**

- **祝福「改行為」不是「加數值」**（改變技能/角色的行為），例如：
  - 「K 的攻擊技命中 → 流血」
  - 「V 的爆發 → 打已流血的敵人傷害翻倍」
  - 「L 的群攻 → 全體敵人緩速」
  - 「換人上場的新人 → 當輪改成能動一次」（連戰鬥規則都能被祝福改寫）
- **深度來源 ＝ 狀態互相咬合**：上狀態的祝福（流血/中毒/易傷/緩速）＋吃狀態的祝福（對流血目標必爆…）＝combo。
  **直接 reuse 現有狀態系統**（流血🩸/中毒🟣/易傷💔/震懾🫨/護盾🛡️…），不用從零造。
- **祝福綁「技能類型/標籤」，不綁「具體招式」**（❌「K 的雙擊」→ ✅「K 的攻擊技」）。
  → 未來換技能不懸空；延續遊戲既有「資料驅動、只讀技能 type、不寫死角色/招式名」的哲學（同 `js/10_戰鬥AI.js`、遺物系統）。
  主要綁「角色＋類型」（養 build 主題），少量通用。也可綁「機制」（如換人），天生不受換技能影響。
  換技能與祝福是好搭檔：換技能改變手上的技能類型組合、祝福往那些類型上疊。
- **從哪撿**（幾乎不用新增節點，現有節點改定位）：🔮奇異地形（安全給）、精英/Boss 勝利（更好的）、代價交換（用血/資源換更強的）、寶藏；給的時候用**三選一**。
- **欄位有上限**（靠永久歷練解鎖）：縫合永久層與單趟層、防膨脹；撿新的要不要蓋舊的＝取捨。
- **稀有度**：**2 階（強化前/後）**（別學黑帝斯搞 5 階，工作量會爆）。
  - 撿的當下**骰品質**：大概率強化前、小概率直接強化後。
  - **重複撿到同一個祝福 → 升級成強化後**（處理重複、不嘔）。
  - **強化後要帶「質變／多一層咬合」，不只是數值 ×2**（守住「改行為不加數值」）。
  - 機率 ＝ **固定基礎值 ＋ 單趟來源**（某些祝福/遺物/事件這趟提高一下）；**不永久累積**。

## 4. 遺物（下放成局內的「有代價道具」）

- 從「成就的永久 always-on 獎勵」**下放**成「路上撿、這趟的道具」。
- **固定有好有壞**（正面＋負面兼有）＝高風險賭注，「撿不撿」是真抉擇。
  負面要**跟 build 取捨掛鉤**（例：攻擊+50% 但無法治療＝配激進速攻流；速度翻倍但血量減半＝速攻流會賭），
  **別做死負面/坑人負面**（如 -50% 全隊血、或偷偷坑人）。
- **戰鬥中不能插拔**（能自由拔＝負面可規避＝形同虛設，就退化成純正面、跟祝福重複）；撿了固定生效這趟。
- **安全點可「永久丟棄」一個遺物**（丟了不能反悔、不能暫拔再裝回）；這個「拔遺物」選項**會排擠安全點的其他選項**（拔遺物也是取捨、不免費）。
- 對比：祝福純正面（插不插拔無所謂），「不能插拔」這規矩只對有負面的遺物有意義。

## 5. 成就（純榮譽/收藏，完全不碰強度）

- 成就**不再綁遺物、不給任何能力/強度**。給的是**潛晶買不到的獨特榮譽貨**：稱號、名字/血條花俏特效、收藏品、通關紀錄。
- **零平衡影響**：解再多成就都不會變強 → 徹底解決「全成就會很強」。接上賭場那塊早就規劃的「純外觀酷東西」。
- 「實力（潛晶）」和「獎盃櫃（成就）」本質不同、一眼不重複。
- ❌ 已丟棄：「幸運值」點子（會偷渡永久強度，是先前一連串糾結的源頭，丟掉最乾淨）。

## 6. 戰鬥系統

**引擎保留、只加層**：回合制、隊伍、看意圖、飄傷害數字都留著（不重寫，降風險）。

- **帶四上三**：每次出發最多帶 4 人（劇情理由：人太多會影響行動速度），場上 3 人、**中間 1 人待命**。
  - **待命安全（敵人打不到）**：劇情設定「要有三人才足夠保護中間的第四人」——待命者被前排三人護在中間、打不到，也因此不能動。
  - **有人倒下 → 待命者自動往前補上**（不用花回合換）；**四人全倒才算全滅**。
  - 待命區回血**很慢**（本來就慢；不是拿來養血的——換人花一整個回合根本不划算）。**換人不另設冷卻**，花掉一個回合本身就是代價。
  - 角色不足 4 人時（如 K 離隊）：「最多帶 4」是上限，不足就全帶、有幾個上幾個（剩三人＝三人全上、沒待命席——剛好演出「失去 K 的緊繃」）。
- **初始上場陣容**：每場戰鬥的先發＝**接續上一場結束時的樣子**；要調整在**戰鬥外**改。
- **換人**：輪到某在場角色時，行動選項多一個「換人」，**消耗被換下去那個角色的回合**（他這回合不出手）；
  **換上來的新人當回合不動**、下一輪才依速度行動（避免一回合兩動）。**（已敲定）**
- **四缺一抉擇**：現在剛好四人（L 群攻／V 爆發／主角戰士／K 奶）。每個「不帶」都要有清楚會痛的後果：
  不帶 K＝放棄穩定治療（靠藥硬撐、滿編輸出）／不帶 L＝群怪吃力／不帶 V＝打 Boss 精英磨很久／不帶主角＝隊伍脆、後排挨打。
  - **治療要有 K 以外的替代來源**（藥/魔藥/祝福），讓「不帶 K」是有代價但可行的激進選擇（否則 K 必帶＝假抉擇）。
  - 角色變多後，出發選 4 個 ＝ roguelite 組隊的第一個大決策。
- **速度／先攻**：每個角色/敵人一個速度數字、會被各種效果影響；**簡化版＝每輪開始依速度排序**（不做即時 ATB）。
  控場（震懾類）統一做成「降速／這輪跳過」。速度是角色的既定設定之一（例：V ＝低速）。
- **技能：次數制 → 冷卻制**（跟敵人同一套，敵人本來就是冷卻；場內每回合決策「這回合放哪招」；祝福可減 CD 或 CD 好時附效果）。
- **難度分工**：
  - 「一整趟」的難度（跨場耗損）＝ 血/補血藥/魔藥有限 ＋ 待命恢復慢。
  - 「單場」好不好玩（場內節奏）＝ 冷卻 ＋ 換人 ＋ 速度。
  - 技能次數退場，那個「耗損維度」交給血扛。

## 7. 王牌（稀有爆發資源）

- **一大關一顆**，**單趟資源**（消散）。保持純粹：一個效果、很少、很強，別長成雜務。
- **用掉 ＝ 清空「指定單一角色」的所有冷卻**（技能本來就沒幾個，就是清一次冷卻：讓那角色接下來不必等 CD、能立刻放想放的招）。救場／爆發兩用。
- **沒用掉 ＝ 關末換一份小獎勵**：一小筆潛晶（給「一趟收入的零頭」，別大到誘導囤著不用），或下關的局內起手優勢。
  → 消掉「囤積焦慮」：用掉救這關 vs 忍住換下關開場禮，兩邊都不虧、選擇還在。
- 其他爆發效果（全隊護盾、免疫一次致命傷…）**先存點子庫**，別一次用光；「清空冷卻」當第一個用途。

## 8. 探索結構

- **一趟 run ＝ 從據點出發、一路往深潛**（能連續穿過好幾層），路半隨機、build 一路堆、越深怪越硬也越給，
  直到「見好就收回家」或「全滅被捲回」。**這才有隨機、build 成形、越深越險、貪心 vs 收手。**
  （❌ 作廢的錯誤想法：「一趟＝一個圈層、從任意層出發」——那會把隨機/越深越險/貪心全閹掉。）
- **據點（原「避難所」）**：保留一個**固定據點**承載 meta 功能（升歷練/解鎖技能/整備/圖鑑/賭場/劇情）＋當**時間線倒回的錨點**。
  - 敘事上他們是**背帳篷的探險隊、一路前行、沿路紮營**（浪漫感靠 run 途中的休息點紮營來演），
    但功能性的據點是固定的（輪迴把兩者縫起來：主角每次死，時間線倒回到「他們還在據點」那一刻）。
  - （據點可換個更符合探險隊的稱呼，別叫「避難所」也行。）
- **淺層重複性**：靠路半隨機＋每趟 build 不同＋怪組合有變化（fixed encounter 可多組）撐住不無聊（黑帝斯模式）。
- **待調的手感**：每趟從第一層往下潛、挑戰深層要先過淺層——要不要給「捷徑/檢查點」跳過已通關淺層，是可調節奏選擇，不影響架構。

### 篝火（取代原「毯子堆」）
- 位置：**Boss 前的固定休息點**（第四層規劃已定「Boss 前一格一定是休息點」）有一個**篝火**；先選休息（恢復），然後**可以**看舊的或新解鎖的小劇情。
- 呼應探險隊紮營氛圍、大戰前喘息的情緒節奏，融進 run（不再是「家的選單」）。
- **內容結構：每一層 × 每個角色各一段**篝火小劇情。
- **解鎖**：在那一層達成某些條件（會寫明、**不會太難**，**考慮做成「不同輪迴累計」**＝跨趟 run 累積、細水長流）就解鎖。
- 好規則沿用（原毯子堆）：**未讀高亮、沒新的就不打擾**（重複 run 不會被煩到）。
- **主線 vs 篝火分工**：主線大劇情走「新關卡/Boss 門前」（推進度）；篝火＝**可重複看的角色小品**（養角色、深化情感、輕鬆）。
  建議篝火小劇情定位成「可回顧的角色小品、跟主線因果分開」，就不用糾結輪迴邏輯、不會打結。

## 9. 劇情 / 教學結構

- **序章 ＝ 救 L**：救到 L 才算序章結束，這樣序章末**四人到齊**，核心循環（四人小隊、四缺一、換人、待命）從第一趟真正的 run 就運轉。
  - 把教學**融進「第一次深潛、目標救 L」**，教學就不枯燥、是邊玩邊學。注意序章別太長。
  - （會需要重排現有第一/二層的劇情——L 原本後面才救。）
- **邀請出發劇情**（序章末、四人到齊時）：K/V/L 說出願望——「一起逃出這裡、不要只是苟延殘喘」，
  「一旦往深處走，或許就不能回頭」，「（主角），我們想邀請你一起出發。」
  → 給 roguelite 循環一個**情感動機**（往下闖是為了共同願望，不只是刷）；當主循環的「開場鑼」。
  這段的「希望」寫得越亮，之後輪迴每一次倒下的影子越長（是輪迴 meta 的情感燃料）。
- **劇情觸發規則**（納可拍板）：
  - **死亡回歸靜默、沒有任何劇情**（唯一特例：第一次死亡回家 K 那句潛晶伏筆，之後靜默）。
  - **只有「到新關卡」才播劇情**，且**只播第一次；第二次看會問「是否跳過」**（reuse 現有 `skipDialogue`）。
  - 劇情靠「一次性永久旗標（如現有 `layerNCleared`/`bossNDoorShown`）＋據點推進」保持連續，跟「單趟 build 會重來」完全分開。

### K 消失 → 被控 → 救回（跟 roguelite 共存的做法，納可拍板）
- **失去 K 的影響精準限定在「第四關 Boss 戰」**，不污染其他 run（K 消失若做成據點永久狀態，會害回頭刷淺層也被迫三人，故不那樣做）。
- **K 在第四關王前的固定休息點才消失**（被抓走），這場王戰（明鏡🪼＋被控 K）用剩下的人打，只有這場變難。
- 情感更集中：那場是**打倒自己的夥伴才能救他**（被控 K 站對面攻擊、還幫王補血；用 `js/10_戰鬥AI.js` 翻面），比長時間三人更狠。
